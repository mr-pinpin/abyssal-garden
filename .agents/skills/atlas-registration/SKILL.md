Read the atlas-field-compiler and render-evaluator skills only for their relevant inputs/evidence rules. Open actual source art and the route survey in canon `docs/storyboard/atlas-geometry.js`, or the versioned recorded coordinates and hashes in `assets/atlas-studies/registration.json`. Region/canopy/roof silhouette centers are not ground contacts. The first atlas metadata's approximate landmark percentages are not surveyed centers.

Read current renderer route, measured house plan, Elder envelope and the actual bridge GLB deck. Include model scale, yaw and local deck asymmetry when transforming endpoints; a descriptor origin need not be the geometric center. Preserve local measured architecture while treating outdoor stage positions as explicit authoring choices.

Fit only declared ground anchors with uncertainty. Keep independent checkpoints out of the fit: tractor side/position, crossing endpoints and bridge axis, route/shore overlap, plant footprints and building entrances. Three exact affine residuals and an invertible matrix establish neither geographic correctness nor placement safety. Check determinant/folds, support domain and inverse. Reject extrapolation and unsupported terrain or foliage consumers; diagnostic lookup must not become an accepted placement API by accident.

The original v1 staged-world fit was rejected: the tractor is west of its bridge while the atlas places it east/southeast, and the crossing axis differs by about77degrees. Do not force a global transform merely to keep all authored positions unchanged. A recorded migration candidate uses the ground doorway approach, Elder route end and traced crossing midpoint; it requires explicit tractor relocation, bridge yaw/scale/center correction and a real path update before acceptance. A mask-region center produced an additional0.93unit deck-midpoint error and was rejected. These are observed source-specific lessons, not universal fit tolerances.

Observed in layout v2: a navigation target is not necessarily an object origin. Atlas tractor navigation(1248,820) marks the road approach; independently reviewed visible tire contacts put its support representative near(1335,793) with about12pixel uncertainty. Retain approach and object placement separately, including actual GLB wheel offsets. If a reviewed point is then used to place the object, its zero residual is construction, not independent validation. Raised deck thresholds differ from traced approach endpoints by about0.9scene units under this authored affine; retain that oblique-projection uncertainty and the independent rail/deck checkpoint artifact. The migrated crossing/tractor/route is an accepted authored-layout increment, while broad foliage and height consumers remain gated pending full-radius exclusions and shoreline checks. The original rejected v1 artifact is retained for history.

Version migrations with source hashes, forward/inverse, accepted purposes/domains, residuals, ground/exclusion bounds and remaining uncertainty. Re-run tests against actual moved geometry, not only fitted controls. Verify dry walking clearance and deck contact, full canopy radius/spacing, shoreline/water continuity and matched overview/eye-level GPU views. Generated bare-earth heights remain artist-estimated; world height scale is a separate authored contract, never silently metric truth.

Use the existing registration tool/tests/diagnostic. A staged-anchor change must force intentional versioning rather than reuse a stale artifact. Publish a consumer contract only after its layout and exclusion checks pass. Record request, execution, commit and live verification where observed; leave missing times null. Update this skill narrowly from demonstrated registration or review failures, with evidence. Keep the high-level visual-quality objective open until its real criterion is met.

For a generated-texture runtime, keep decoded data and sampling formats explicit. `source/tools/atlas-runtime.mjs` consumes the generated height/class images and emits `runtime-v3.json`; CI compiles it before release so edited images cannot leave stale world data. A categorical RGB class image is NOT the shader's packed RGBA material weights: require an explicit decoder contract. Test a real generated-height source substitution with fixed camera/light/class inputs and actual GPU pixels, not only a JSON hash.

In the first runtime draft, steep banks and disconnected canopy placement were rejected by GPU inspection. Bound reconstructed terrain slopes and evaluate smooth derivative normals while retaining raw height input/provenance. When a mesh normalizes its local base to zero, moving it to sampled terrain must preserve the existing mesh-base offset; overwriting piece.position.y drops canopies to the ground. A built-scene canopy-versus-trunk height regression now checks this. Existing study GLBs may contain whole miniature scenes: an unseeded rectangular water/log patch was removed rather than disguised as an atlas prop.

A common normalized atlas-frame overlay proves projection alignment, not 1:1 authored content or photorealism. Preserve independent landmark/appearance review and explicit legacy-template debt. A 1536px top-down readback timed out on the VPS software GPU; a960px frame covering the same full normalized extent passed. Record that resource limit without converting it into a hardware-performance claim.
