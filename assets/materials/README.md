# Generated woodland materials

Six 1024×1024 ChatGPT image-generation assets, in renderer order:
`grass.webp`, `path.webp`, `mud.webp`, `rock.webp`, `bark.webp`, `moss.webp`.
Prompts, timestamps, tool/model disclosure, source/output hashes, dimensions and
repeat-check diagnostics are in `provenance.json`. These are base-color images,
not measured physical material scans or normal/height/roughness maps.

The original generated images remain unchanged in the generation archive.
Runtime assets are high-quality resampled WebP derivatives (quality 0.92), about
3 MB combined; the loader uploads six 512×512 layers. All six were visually
reviewed in 2×2 repetition. Natural variation can still reveal repetition at
large scale; exact opposite-edge pixel equality is not claimed.

The book's warm natural palette guided the prompts, with flat diffuse light
requested so world lighting stays the renderer's responsibility. No synthetic
test-noise materials are included. No exclusive copyright claim is made for
AI-generated imagery; software licensing does not turn these into measured data.
