Rendering iteration: foliage and sky

Actual GPU readbacks at matching camera, 960×640 viewport, DPR 1, Chrome 157 and SwiftShader. Reduced motion fixes the animation pose; each capture waits for tree fading to settle.

This is a camera/hardware-matched visual comparison, not a quality-normalized performance benchmark. The new geometry has a higher GPU detail budget; leaf shading and sky also changed. Pixel differences are not a photorealism score.

What remains

The current scene is still below the atlas/book’s material richness. Terrain registration, natural canopy variation, cast shadows, bark/leaf detail and the sparse eye-level distance need further work. Passing geometry tests alone did not establish this result: earlier leaf drafts were rejected as too bare, and the build’s missing-plugin path was caught before deployment.
